# Code of Conduct

upgradescope has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the project,
in every project space: issues, pull requests, discussions, reviews, and any
other channel where you represent the project.

We ask for the plain version of it. Be respectful and assume good faith.
Critique code and data, not people. Harassment and personal attacks are not
tolerated.

## Reporting

To report behaviour that violates the code of conduct, contact the maintainer
privately:

- Use GitHub's private reporting on this repository:
  [Security → Report a vulnerability](https://github.com/abd-ulbasit/upgradescope/security/advisories/new).
  The channel is built for security reports, but it is also the private route
  for conduct reports. Put "Code of Conduct" in the title.
- Or contact the maintainer, [@abd-ulbasit](https://github.com/abd-ulbasit),
  through the contact details on their GitHub profile.

Reports are kept confidential. The maintainer will respond and act in line
with the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
which run from a private correction up to a permanent ban.
