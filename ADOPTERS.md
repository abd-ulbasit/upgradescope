## How to add yourself

Open a pull request that adds a row to the table:

- **Organisation**: its name, linked to its site if you like.
- **Contact**: a GitHub handle the maintainers can ask a question of.
- **Since**: the month you started, as `YYYY-MM`.
- **How it is used**: one line, for example "the GitHub Action gates our
  Helm charts' pull requests", or "the agent in 12 clusters, with `serve`
  for the fleet view".

Once the project's Discussions has an adopters thread, a comment there with
the same four fields works too, and a maintainer adds the row for you.

If you use upgradescope but cannot be named, the maintainers still want to
hear what works and what does not: open an issue or a discussion.
