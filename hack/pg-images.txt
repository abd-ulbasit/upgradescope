# Postgres majors the pg-conformance CI job runs the store conformance
# suite against, one image each, pinned by the digest of its multi-arch
# index. Read by hack/pg-images.sh (the job's matrix and its service image).
#
#   <major> <postgres image, pinned by digest> <pr|weekly>
#
# pr      every pull request, push to main and release run (plus weekly)
# weekly  the scheduled run and workflow_dispatch only
#
# The tag a digest came from is the image name before the @ (postgres:17).
# A tag moves with every patch release, so CI, and the release-gating run
# release.yml calls, pull exactly these bytes until someone bumps them (#244).
# Dependabot does not see workflow service images: bump by hand, every
# major in one commit, with the index digest Docker Hub serves for the tag:
#
#   tok=$(curl -s "https://auth.docker.io/token?service=registry.docker.io&scope=repository:library/postgres:pull" | jq -r .token)
#   curl -sI -H "Authorization: Bearer $tok" \
#     -H 'Accept: application/vnd.oci.image.index.v1+json' \
#     -H 'Accept: application/vnd.docker.distribution.manifest.list.v2+json' \
#     https://registry-1.docker.io/v2/library/postgres/manifests/17 | grep -i docker-content-digest
#
