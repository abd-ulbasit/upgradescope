# pr      every pull request and push to main (plus weekly)
# weekly  the scheduled run and workflow_dispatch only
#
# PRs run the oldest minor with the flowcontrol.apiserver.k8s.io v1beta3
# window (1.31, the #3 false-blocker case) and the newest; the weekly run
# covers every minor from 1.29 up.
#
# Each image is the newest patch of its minor that a kind release built,
# with the digest copied from that release's notes
# (https://github.com/kubernetes-sigs/kind/releases); always pin the digest,
# a kindest/node tag alone is not tied to one kind release. hack/install-tool.sh
# pins kind itself (v0.33.0). Images from older kind releases are not
# guaranteed to work with a newer kind; if one stops booting or `kind load`
# fails on it, take that minor's image from the newest kind release that
# built it, or drop the minor to weekly with a note.
